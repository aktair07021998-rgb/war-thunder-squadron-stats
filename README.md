Для каждого режима вычитаем первый накопительный счётчик из второго. Пропущенный замер или уменьшение счётчика даёт прочерк в итоге этого режима. Число СБ зелёное при перевесе СБ и красное при перевесе РБ. При равенстве оба итога нейтральны. В скобках указан перевес в боях.
